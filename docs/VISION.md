# CreatorOS

CreatorOS is a private single-user content scheduling and publishing assistant.

Mission:
Help one creator prepare content, choose a posting time, and manage a publishing queue.

The creator focuses on making content.

The intended workflow is select a video, choose a platform, prepare metadata,
review a posting-time recommendation or choose a time, and add the post to a queue.
Publishing and subsequent performance snapshots will complete that loop later.

Today the application has a local content library and clearly marked placeholders
for the rest of the workflow. Platform priority is YouTube, Instagram, then TikTok.
Performance history is preserved as an internal scheduling input. There is no
CreatorOS login, analytics dashboard, billing, or team/workspace product.

See `SCHEDULING.md` for the next implementation boundary. OAuth, publishing,
metadata generation, and statistical recommendations require separate work.
